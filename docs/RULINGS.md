October 20, 2026. **Strategist's rulings on J-8, under the October 16 adoption of the audit:** (a) An event passes the timing test but the market readings do not agree, with no other named cause: the grade is Unclear, and the card prints its own line for this case, "A reported event lines up in time, but the market readings do not match it," naming the event, so the reader sees both facts and no cause is claimed. No card is the wrong default here, because the page would be silent about a move it has evidence on. (b) The page's window moved the other way from the run the timing test measured: no card, and the page prints "Verdict at the next read" in the card's place; the next slot's run grades the move as it then stands. The boundary: 25 percent or more of the move done before the first report disqualifies the event; twenty-five exactly disqualifies. The clock: the timing test measures from the first-report time, which is the moment the market could have reacted; for a scheduled release the event time and the report time coincide, and for an event reported after it happened (a hack, a filing found later) the report time governs and the move before it is not the event's. Where 9.2 measured from the event time, the change to the first-report time goes into the first sprint that touches why_evidence.py (9.9 at the latest), with the fixtures re-run and a fixture whose grade changes listed in that report. Likely's printed definition: "The reported events that pass the timing test, with the market readings agreeing." When more than one event passes and they point the same way, the card is one Likely that names each of them; when they point opposite ways, the grade is Disputed and the card states both. The 14 October case with two 8:30 AM releases is one Likely naming both.
